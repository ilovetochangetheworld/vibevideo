# 小样筛选与可执行评审

## 先小样，再扩展

新建画面方向不明确时，先明确成片形式、受众应理解的变化和可观察的质量标准。做约10秒小样，选择少量有意义的方向比较：可以比较配色/材质，也可以比较镜头/动作；说明比较的是哪一项，换色不等于测试了两套完整动效风格。不要为了数量复制大量同质版本。

先检查小样，再记录选择理由并扩展整片。追求专业定制水准，但把目标拆成可观察的构图、动作、文字、材质和节奏；“获奖级”不是验收证据。不为试做设置额外逐步确认，用户有新方向时再调整。成熟方向的音频修改可跳过视觉小样。

## 七项检查

| 维度 | 关注点 |
|---|---|
| 风格 | 视觉语言与题材相符；颜色和材质含义一致 |
| 创意 | 是否有帮助理解的视觉转化或揭示；装饰是否抢走主题 |
| 动效 | 起止、补位、镜头与归组连贯；不是静态卡片轮流亮起 |
| 排版 | 手机尺度可读；近景、缩放、浅色背景都不遮挡字幕 |
| 质感 | 主体轮廓、层次与接触关系清楚；辉光不过度 |
| 声音与同步 | 旁白完整，结论时机相符，单一BGM稳定；未听过就保留听感未核验状态 |
| 技术 | 同一时间可重现；时长/帧数/轨道/解码符合交付要求 |

有可用且获授权的独立评审时，让评审从实际成片和必要事实条件出发，不把制作代理的自评结论当依据。否则做逐项自检，写清评审身份；不自动要求委派。分数若使用，应说明是主观量表；事实错误、遮挡、截字、错轨等不能靠平均分抵消，也不承诺达到9分或获奖级。

把反馈记入`review/revision-log.md`：时间点、可观察的问题、对理解的影响、修复动作、复查证据。按影响最大的几项修改，重新截取同一时刻和转场，已通过的部分不无故重做；局部改动可只重渲受影响区间，并核对接回后的帧数与音轨。

## 可复用提示词要点

制作：说明成片形式、主题、已有素材/声音、视觉语义和交付格式；先做短小样，动作承载解释，保留源码和修改记录。有/无BGM输出同一画面和旁白。

评审：只按实际成片提出带时间点的具体问题与修改建议，先看影响理解的短板；没有看过或听过的部分不能打分。修订后复查同一时段。

方法参考：[Vincent 的视频制作教程](https://www.douyin.com/video/7697976597185435475)（2026-10-18），其短demo、七维度评审与迭代思路经本地试做调整。模型型号、作者自评分数、“不用skill”等实验条件不作为本skill的固定要求。
